# 运维设计

## 概述

本文档描述 Ling-iflow 项目的监控、日志、故障处理和性能优化策略。

## 监控和日志

### 1. 日志系统

**技术方案**：
- 使用 loguru 作为日志库
- 支持多级别日志（DEBUG, INFO, WARNING, ERROR）
- 支持日志文件输出

**配置**：
```json
{
  "log_level": "INFO",
  "log_file": "/path/to/log/file"
}
```

**实现**：

```python
from loguru import logger
import sys

def setup_logging(log_level: str = "INFO", log_file: str = ""):
    """配置日志系统。"""
    # 移除默认处理器
    logger.remove()
    
    # 添加控制台输出
    logger.add(
        sys.stdout,
        level=log_level,
        format="<green>{time:YYYY-MM-DD HH:mm:ss}</green> | <level>{level: <8}</level> | <cyan>{name}</cyan>:<cyan>{function}</cyan>:<cyan>{line}</cyan> - <level>{message}</level>",
        colorize=True
    )
    
    # 添加文件输出（如果指定）
    if log_file:
        logger.add(
            log_file,
            level=log_level,
            format="{time:YYYY-MM-DD HH:mm:ss} | {level: <8} | {name}:{function}:{line} - {message}",
            rotation="00:00",  # 每天午夜轮转
            retention="30 days",  # 保留 30 天
            compression="zip"  # 压缩旧日志
        )
```

**日志级别**：
- **DEBUG**：详细的调试信息
- **INFO**：一般信息
- **WARNING**：警告信息
- **ERROR**：错误信息

### 2. 统计信息

**技术方案**：
- 实时统计发送/接收消息数量
- 统计错误数量
- 获取服务运行状态

**统计字段**：
```python
{
    "messages_sent_to_iflow": int,      # 发送到 iflow 的消息数
    "messages_synced_to_wechat": int,   # 同步到企业微信的消息数
    "errors": int,                      # 错误数量
    "wechat_enabled": bool,             # 企业微信是否启用
    "running": bool                     # 是否运行中
}
```

**实现**：

```python
class SyncManager:
    def __init__(self):
        self.stats = {
            "messages_sent_to_iflow": 0,
            "messages_synced_to_wechat": 0,
            "errors": 0,
        }
    
    async def send_to_wechat(self, message: Dict) -> None:
        """发送消息到企业微信。"""
        try:
            # 发送消息
            success = await self.wechat_channel.send(...)
            
            if success:
                self.stats["messages_synced_to_wechat"] += 1
            else:
                self.stats["errors"] += 1
        except Exception as e:
            self.stats["errors"] += 1
            logger.error(f"Error sending to WeChat: {e}")
    
    def get_stats(self) -> Dict:
        """获取统计信息。"""
        return {
            **self.stats,
            "wechat_enabled": self.wechat_channel is not None,
            "running": self.running
        }
```

## 故障处理

### 1. iflow CLI 异常

**处理方案**：
- 定期检查 iflow 是否运行
- 自动重启 iflow
- 记录错误日志
- 通知用户

**实现**：

```python
class SyncManager:
    async def _monitor_loop(self):
        """监控循环。"""
        while self.running:
            try:
                # 检查 iflow 是否运行
                if not self.controller.check_iflow_running():
                    logger.warning("[SyncManager] iflow not running, attempting restart...")
                    success = self.controller.start_iflow()
                    
                    if success:
                        logger.info("[SyncManager] iflow restarted successfully")
                    else:
                        logger.error("[SyncManager] Failed to restart iflow")
                        await self.wechat_channel.send(
                            "❌ iflow 异常退出，重启失败，请检查日志",
                            self.wechat_channel.config.user_id,
                            is_group=False
                        )
                
                # 检查新消息
                if self.monitor.should_check():
                    new_messages = self.monitor.read_new_assistant_messages()
                    for msg in new_messages:
                        await self.send_to_wechat(msg)
                
                await asyncio.sleep(0.2)
            except Exception as e:
                logger.error(f"[SyncManager] Monitor loop error: {e}", exc_info=True)
                await asyncio.sleep(1)
```

### 2. 网络异常

**处理方案**：
- HTTP 请求超时重试
- 网络断开自动重连
- 消息队列缓存
- 错误信息反馈

**实现**：

```python
import asyncio

async def send_with_retry(self, url: str, payload: dict, max_retries: int = 3) -> bool:
    """发送消息（带重试）。"""
    retry_count = 0
    
    while retry_count < max_retries:
        try:
            async with httpx.AsyncClient(timeout=10.0) as client:
                response = await client.post(url, json=payload)
                result = response.json()
                
                if result.get("errcode") == 0:
                    return True
                else:
                    logger.error(f"API error: {result}")
                    return False
        
        except asyncio.TimeoutError:
            logger.warning(f"Timeout (attempt {retry_count + 1}/{max_retries})")
            retry_count += 1
            await asyncio.sleep(2 ** retry_count)  # 指数退避
        
        except Exception as e:
            logger.error(f"Error sending message: {e}")
            retry_count += 1
            await asyncio.sleep(2 ** retry_count)
    
    return False
```

### 3. 消息发送失败

**处理方案**：
- 记录失败消息
- 支持手动重发
- 提供失败原因
- 通知用户

**实现**：

```python
class WechatWorkChannel:
    def __init__(self):
        self._failed_messages: List[Dict] = []
    
    async def send(self, content: str, chat_id: str, **kwargs) -> bool:
        """发送消息。"""
        try:
            success = await self._send_to_api(content, chat_id, **kwargs)
            
            if not success:
                # 记录失败消息
                self._failed_messages.append({
                    "content": content,
                    "chat_id": chat_id,
                    "timestamp": time.time()
                })
                
                # 保持失败消息列表在合理大小
                if len(self._failed_messages) > 100:
                    self._failed_messages.pop(0)
            
            return success
        
        except Exception as e:
            logger.error(f"Error sending message: {e}", exc_info=True)
            return False
    
    async def retry_failed_messages(self) -> int:
        """重试失败的消息。"""
        retry_count = 0
        
        for msg in self._failed_messages.copy():
            success = await self.send(
                msg["content"],
                msg["chat_id"]
            )
            
            if success:
                self._failed_messages.remove(msg)
                retry_count += 1
        
        return retry_count
```

## 性能优化

### 1. 进程管理

**技术方案**：
- 异步进程检查
- 批量操作支持
- 进程池管理

**实现**：

```python
import asyncio

async def check_process(pid: int) -> bool:
    """检查进程是否运行。"""
    try:
        proc = await asyncio.create_subprocess_exec(
            "ps", "-p", str(pid),
            stdout=asyncio.subprocess.PIPE,
            stderr=asyncio.subprocess.PIPE
        )
        stdout, _ = await proc.communicate()
        return proc.returncode == 0
    except Exception:
        return False

async def check_multiple_processes(pids: List[int]) -> Dict[int, bool]:
    """检查多个进程。"""
    tasks = [check_process(pid) for pid in pids]
    results = await asyncio.gather(*tasks)
    return dict(zip(pids, results))
```

### 2. 日志管理

**技术方案**：
- 日志轮转
- 日志压缩
- 日志清理策略

**实现**：

```python
from loguru import logger
import os

def setup_log_rotation(log_file: str):
    """配置日志轮转。"""
    logger.add(
        log_file,
        rotation="100 MB",  # 文件大小超过 100MB 时轮转
        retention="7 days",  # 保留 7 天
        compression="zip",  # 压缩旧日志
        level="INFO"
    )

def cleanup_old_logs(log_dir: str, days: int = 30):
    """清理旧日志。"""
    cutoff_time = time.time() - days * 24 * 3600
    
    for filename in os.listdir(log_dir):
        filepath = os.path.join(log_dir, filename)
        
        if os.path.isfile(filepath):
            file_mtime = os.path.getmtime(filepath)
            
            if file_mtime < cutoff_time:
                os.remove(filepath)
                logger.info(f"Removed old log file: {filename}")
```

### 3. 资源监控

**技术方案**：
- 内存使用监控
- CPU 使用监控
- 网络连接监控

**实现**：

```python
import psutil

def get_memory_usage() -> Dict[str, float]:
    """获取内存使用情况。"""
    process = psutil.Process()
    mem_info = process.memory_info()
    
    return {
        "rss": mem_info.rss / 1024 / 1024,  # MB
        "vms": mem_info.vms / 1024 / 1024,  # MB
        "percent": process.memory_percent()
    }

def get_cpu_usage() -> float:
    """获取 CPU 使用率。"""
    return psutil.cpu_percent(interval=1)

def get_network_connections() -> List[Dict]:
    """获取网络连接。"""
    process = psutil.Process()
    connections = process.connections(kind='inet')
    
    return [
        {
            "laddr": f"{conn.laddr.ip}:{conn.laddr.port}",
            "raddr": f"{conn.raddr.ip}:{conn.raddr.port}" if conn.raddr else "N/A",
            "status": conn.status
        }
        for conn in connections
    ]
```

## 健康检查

### 1. 健康检查接口

**实现**：

```python
from aiohttp import web

class HealthCheckHandler:
    """健康检查处理器。"""
    
    def __init__(self, sync_manager: SyncManager):
        self.sync_manager = sync_manager
    
    async def health_check(self, request: web.Request) -> web.Response:
        """健康检查。"""
        # 检查 iflow 是否运行
        iflow_running = self.sync_manager.controller.check_iflow_running()
        
        # 检查企业微信是否可用
        wechat_available = (
            self.sync_manager.wechat_channel is not None and
            self.sync_manager.wechat_channel._access_token != ""
        )
        
        # 获取统计信息
        stats = self.sync_manager.get_stats()
        
        # 检查服务状态
        healthy = (
            self.sync_manager.running and
            iflow_running and
            (not stats["wechat_enabled"] or wechat_available)
        )
        
        status_code = 200 if healthy else 503
        
        return web.json_response({
            "status": "healthy" if healthy else "unhealthy",
            "iflow_running": iflow_running,
            "wechat_available": wechat_available,
            "stats": stats
        }, status=status_code)
```

## 部署建议

### 1. 系统要求

**最低配置**：
- CPU：2 核
- 内存：2 GB
- 磁盘：10 GB
- 操作系统：Linux（推荐 Ubuntu 20.04+）

**推荐配置**：
- CPU：4 核
- 内存：4 GB
- 磁盘：20 GB
- 操作系统：Linux（推荐 Ubuntu 22.04+）

### 2. 依赖安装

```bash
# 安装 Python 3.10+
sudo apt update
sudo apt install python3.10 python3.10-venv

# 安装 tmux
sudo apt install tmux

# 安装 iflow CLI
# 参考 iflow 官方文档

# 安装 Ling-iflow
pip install -e .
```

### 3. 服务配置

**使用 systemd 管理服务**：

```ini
# /etc/systemd/system/ling-iflow.service
[Unit]
Description=Ling-iflow Service
After=network.target

[Service]
Type=simple
User=ling-iflow
WorkingDirectory=/opt/ling-iflow
Environment="PATH=/opt/ling-iflow/venv/bin"
ExecStart=/opt/ling-iflow/venv/bin/ling-iflow start --wechat
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

**启动服务**：

```bash
# 启用服务
sudo systemctl enable ling-iflow

# 启动服务
sudo systemctl start ling-iflow

# 查看状态
sudo systemctl status ling-iflow

# 查看日志
sudo journalctl -u ling-iflow -f
```

### 4. 反向代理配置

**使用 Nginx**：

```nginx
# /etc/nginx/sites-available/ling-iflow
upstream ling_iflow {
    server 127.0.0.1:8788;
}

server {
    listen 80;
    server_name your-domain.com;

    location /wechat/callback {
        proxy_pass http://ling_iflow;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

**启用配置**：

```bash
# 创建软链接
sudo ln -s /etc/nginx/sites-available/ling-iflow /etc/nginx/sites-enabled/

# 测试配置
sudo nginx -t

# 重启 Nginx
sudo systemctl restart nginx
```
