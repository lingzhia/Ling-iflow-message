## 概述

本文档描述 Ling-iflow 项目的关键技术点、数据模型和安全设计。

## 关键技术点

### 1. Tmux 集成

**技术方案**：
- 使用 `tmux new-session -d -s <session> "command"` 创建后台会话
- 使用 `tmux send-keys -t <session> -l <message>` 发送消息
- 使用 `tmux capture-pane -t <session> -p` 捕获输出
- 使用 `tmux list-panes -t <session> -F "#{pane_pid}"` 获取进程信息

**优势**：
- 无需修改 iflow CLI 源码
- 支持远程控制
- 可复用现有 tmux 会话

**实现示例**：

```python
import subprocess

class IFlowController:
    def __init__(self, tmux_session: str = "iflow"):
        self.tmux_session = tmux_session
    
    def check_tmux_session(self) -> bool:
        """检查 tmux 会话是否存在。"""
        try:
            result = subprocess.run(
                ["tmux", "has-session", "-t", self.tmux_session],
                capture_output=True,
                timeout=5
            )
            return result.returncode == 0
        except Exception as e:
            logger.warning(f"[IFlowController] Error checking tmux session: {e}")
            return False
    
    def send_message(self, message: str) -> bool:
        """发送消息到 iflow CLI。"""
        try:
            # 清除当前输入框
            subprocess.run(
                ["tmux", "send-keys", "-t", self.tmux_session, "C-c"],
                capture_output=True,
                timeout=5
            )
            
            # 逐字发送消息
            subprocess.run(
                ["tmux", "send-keys", "-t", self.tmux_session, "-l", message],
                capture_output=True,
                timeout=5
            )
            
            # 发送回车
            subprocess.run(
                ["tmux", "send-keys", "-t", self.tmux_session, "C-m"],
                capture_output=True,
                timeout=5
            )
            
            return True
        except Exception as e:
            logger.error(f"[IFlowController] Error sending message: {e}")
            return False
```

### 2. 异步架构

**技术方案**：
- 使用 asyncio 实现异步消息处理
- 使用 asyncio.Queue 实现消息队列
- 使用 asyncio.create_task 启动后台任务
- 使用 asyncio.gather 并发执行任务

**优势**：
- 高并发处理能力
- 非阻塞 I/O
- 资源利用率高

**实现示例**：

```python
import asyncio

class SyncManager:
    def __init__(self):
        self._wechat_queue = asyncio.Queue()
        self._tasks = []
    
    async def start(self):
        """启动同步服务。"""
        # 启动监控循环
        self._tasks.append(asyncio.create_task(self._monitor_loop()))
        
        # 启动消息处理循环
        self._tasks.append(asyncio.create_task(self._wechat_loop()))
    
    async def _monitor_loop(self):
        """监控 iflow 输出循环。"""
        while self.running:
            try:
                # 检查新消息
                if self.monitor.should_check():
                    new_messages = self.monitor.read_new_assistant_messages()
                    
                    # 发送新消息到企业微信
                    for msg in new_messages:
                        await self.send_to_wechat(msg)
                
                # 等待一段时间再检查
                await asyncio.sleep(0.2)
            except Exception as e:
                logger.error(f"Monitor loop error: {e}")
                await asyncio.sleep(1)
    
    async def _wechat_loop(self):
        """企业微信消息处理循环。"""
        while self.running:
            try:
                # 从队列中取出消息
                msg = await asyncio.wait_for(self._wechat_queue.get(), timeout=1.0)
                
                # 发送到 iflow
                await self._send_to_iflow(msg)
            except asyncio.TimeoutError:
                continue
            except Exception as e:
                logger.error(f"WeChat loop error: {e}")
```

### 3. 消息去重

**技术方案**：
- 使用 MsgId 作为消息唯一标识
- 使用字典缓存已处理的消息 ID
- 定期清理过期的缓存（TTL：1 小时）

**优势**：
- 避免重复处理
- 内存占用可控
- 处理企业微信重试机制

**实现示例**：

```python
import time

class WechatWorkChannel:
    def __init__(self):
        self._msg_cache: Dict[str, float] = {}
        self._cache_ttl = 3600  # 1 小时
    
    def _is_duplicate_message(self, msg_id: str) -> bool:
        """检查是否为重复消息。"""
        current_time = time.time()
        
        # 清理过期缓存
        self._msg_cache = {
            k: v for k, v in self._msg_cache.items()
            if current_time - v < self._cache_ttl
        }
        
        # 检查是否已处理
        if msg_id in self._msg_cache:
            return True
        
        # 记录消息
        self._msg_cache[msg_id] = current_time
        return False
```

### 4. 消息过滤

**技术方案**：
- 过滤思考消息（以 * 开头的行）
- 过滤用户输入（以 > 开头的行）
- 可配置是否启用过滤

**优势**：
- 减少噪音
- 提升用户体验

**实现示例**：

```python
def _filter_thinking_messages(self, messages: List[Dict]) -> List[Dict]:
    """过滤思考消息。"""
    if not self.filter_thinking:
        return messages
    
    filtered = []
    for msg in messages:
        content = msg.get('content', '')
        # 过滤以 * 开头的行（思考消息）
        lines = content.split('\n')
        filtered_lines = [line for line in lines if not line.strip().startswith('*')]
        filtered_content = '\n'.join(filtered_lines)
        
        if filtered_content.strip():
            msg['content'] = filtered_content
            filtered.append(msg)
    
    return filtered
```

### 5. 消息分段

**技术方案**：
- 按行分割消息
- 控制每段最大长度（默认 4096 字符）
- 在段之间添加延迟（0.3 秒）

**优势**：
- 避免超过消息长度限制
- 避免触发企业微信限流

**实现示例**：

```python
import asyncio

async def _split_and_send(self, content: str, chat_id: str, is_group: bool, max_length: int = 4096):
    """分段发送消息。"""
    lines = content.split('\n')
    current_chunk = []
    current_length = 0
    
    for line in lines:
        line_length = len(line)
        
        # 如果当前行超过最大长度，单独发送
        if line_length > max_length:
            # 发送当前块
            if current_chunk:
                await self.wechat_channel.send('\n'.join(current_chunk), chat_id, is_group)
                current_chunk = []
                current_length = 0
                await asyncio.sleep(0.3)
            
            # 分割长行
            for i in range(0, line_length, max_length):
                chunk = line[i:i + max_length]
                await self.wechat_channel.send(chunk, chat_id, is_group)
                await asyncio.sleep(0.3)
        else:
            # 添加到当前块
            if current_length + line_length > max_length:
                await self.wechat_channel.send('\n'.join(current_chunk), chat_id, is_group)
                current_chunk = []
                current_length = 0
                await asyncio.sleep(0.3)
            
            current_chunk.append(line)
            current_length += line_length
    
    # 发送最后一块
    if current_chunk:
        await self.wechat_channel.send('\n'.join(current_chunk), chat_id, is_group)
```

### 1. 会话文件格式（session-*.jsonl）

**说明**：iflow CLI 会将回复写入 `session-*.jsonl` 文件，但在实际实现中，BotIntegration 是通过直接读取 tmux 输出来获取消息的（使用 `tmux capture-pane` 命令）。SessionMonitor 组件可以用来监控 jsonl 文件，但未被实际使用。

每行一个 JSON 对象：

```json
{
  "type": "user|assistant|system",
  "message": {
    "id": "msg-id",
    "content": [
      {
        "type": "text",
        "text": "消息内容"
      }
    ]
  },
  "timestamp": "2026-03-08T12:00:00Z",
  "sessionId": "session-id",
  "uuid": "msg-uuid"
}
```

**字段说明**：
- `type`：消息类型（user/assistant/system）
- `message`：消息内容

- `timestamp`：时间戳（ISO 8601 格式）
- `sessionId`：会话 ID
- `uuid`：消息 UUID

## 安全设计

### 1. 消息加密

**技术方案**：
- 使用 AES-256-CBC 加密消息
- 使用 PKCS7 填充
- 使用 SHA1 验证签名

**实现**：

```python
from cryptography.hazmat.primitives.ciphers import Cipher, algorithms, modes
from cryptography.hazmat.backends import default_backend

class WechatWorkCrypto:
    def __init__(self, encoding_aes_key: str, corp_id: str):
        self.corp_id = corp_id
        self.aes_key = self._decode_key(encoding_aes_key)
        self.iv = self.aes_key[:16]
    
    def decrypt(self, encrypted_msg: str) -> str:
        """解密消息。"""
        import base64
        
        # Base64 解码
        encrypted_data = base64.b64decode(encrypted_msg)
        
        # AES 解密
        cipher = Cipher(algorithms.AES(self.aes_key), modes.CBC(self.iv), backend=default_backend())
        decryptor = cipher.decryptor()
        decrypted_data = decryptor.update(encrypted_data) + decryptor.finalize()
        
        # PKCS7 unpadding
        decrypted_data = self._pkcs7_unpad(decrypted_data)
        
        # 提取消息
        msg_len = decrypted_data[16:20]
        msg_len_int = int.from_bytes(msg_len, byteorder='big')
        msg = decrypted_data[20:20 + msg_len_int]
        
        # 验证 corp_id
        received_corp_id = decrypted_data[20 + msg_len_int:].decode('utf-8')
        if received_corp_id != self.corp_id:
            raise ValueError("Corp ID mismatch")
        
        return msg.decode('utf-8')
```

### 2. 权限控制

**技术方案**：
- 用户 ID 白名单（allow_from）
- 群聊白名单（group_allow_from）
- 群聊 @ 机器人策略（group_policy）

**配置**：
```json
{
  "allow_from": ["user-id-1", "user-id-2"],
  "group_policy": "mention",
  "group_allow_from": ["group-id-1"]
}
```

**实现**：

```python
def _check_user_permission(self, user_id: str) -> bool:
    """检查用户权限。"""
    # 如果白名单为空，允许所有用户
    if not self.config.allow_from:
        return True
    
    # 检查用户是否在白名单中
    return user_id in self.config.allow_from

def _check_group_permission(self, chat_id: str, mentioned: bool) -> bool:
    """检查群聊权限。"""
    # 如果群聊不在白名单中，不允许
    if self.config.group_allow_from and chat_id not in self.config.group_allow_from:
        return False
    
    # 根据 group_policy 决定是否响应
    if self.config.group_policy == "mention":
        return mentioned
    elif self.config.group_policy == "all":
        return True
    else:  # none
        return False
```

### 3. 输入验证

**技术方案**：
- 使用 Pydantic 进行配置验证
- 检查必填字段
- 验证字段类型和格式

**实现**：

```python
from pydantic import BaseModel, Field, validator

class WechatWorkConfig(BaseModel):
    corp_id: str = Field(..., min_length=1)
    agent_id: int = Field(..., gt=0)
    secret: str = Field(..., min_length=1)
    callback_port: int = Field(..., ge=1024, le=65535)
    
    @validator('group_policy')
    def validate_group_policy(cls, v):
        if v not in ['mention', 'all', 'none']:
            raise ValueError(f'group_policy must be one of mention, all, none')
        return v
```

### 1. 异步 I/O

**技术方案**：

**优势**：

### 2. 消息批处理

**技术方案**：
- 会话监控器定时检查（0.2 秒间隔）
- 一次性读取所有新增消息
- 减少文件 I/O 次数

**实现**：

```python
class SessionMonitor:
    def __init__(self):
        self.check_interval = 0.2
    
    def should_check(self) -> bool:
        """检查是否应该执行监控检查。"""
        current_time = time.time()
        if current_time - self.last_check_time >= self.check_interval:
            self.last_check_time = current_time
            return True
        return False
```
