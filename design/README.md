# Ling-iflow 设计文档

本目录包含 Ling-iflow 项目的完整设计方案，从设计总览到具体的模块设计、技术实现和运维管理。

## 文档目录

### 1. [设计总览](./01-设计总览.md)
项目概述、整体架构、核心目标和技术栈。适合初次了解项目的开发者阅读。

### 2. [架构设计](./02-架构设计.md)
详细的架构设计，包括架构图、消息流向、部署架构和关键时间节点。适合需要深入理解系统架构的开发者阅读。

### 3. [模块设计-Channels层](./03-模块设计-Channels层.md)
渠道层的详细设计，包括 BaseChannel 基类和 WechatWorkChannel 企业微信渠道的实现。适合需要扩展新渠道的开发者阅读。

### 4. [模块设计-Interactive层](./04-模块设计-Interactive层.md)
交互层的详细设计，包括 SyncManager、BotIntegration、SessionManager、IFlowController、SessionMonitor 等核心模块的设计。适合需要理解核心逻辑的开发者阅读。

### 5. [模块设计-Config层](./05-模块设计-Config层.md)
配置层的详细设计，包括配置 Schema、配置加载器、机器人配置 Schema 和机器人配置加载器。适合需要管理配置的开发者阅读。

### 6. [模块设计-CLI层](./06-模块设计-CLI层.md)
CLI 层的详细设计，包括所有命令的用法和实现。适合需要使用或扩展命令的开发者阅读。

### 7. [技术设计](./07-技术设计.md)
关键技术点、数据模型和安全设计。适合需要理解技术细节的开发者阅读。

### 8. [运维设计](./08-运维设计.md)
监控日志、故障处理、性能优化和部署建议。适合需要运维和管理系统的开发者阅读。

### 9. [扩展设计](./09-扩展设计.md)
扩展性设计和未来改进方向。适合需要扩展系统功能的开发者阅读。

### 10. [多机器人管理](./10-多机器人管理.md)
多机器人管理方案，包括配置、命令和实现步骤。适合需要管理多个机器人的开发者阅读。

## 文档说明

### 设计总览 vs 原始 DESIGN.md

原始的 `DESIGN.md` 文件包含所有设计方案，内容过于庞大（超过 2000 行），不便查阅和维护。新的设计文档将内容拆分为 10 个独立的文档，每个文档专注于一个特定的设计领域：

- **模块化**：每个文档独立，便于查找和维护
- **结构化**：清晰的目录结构，便于导航
- **详细化**：每个文档都包含详细的设计说明和代码示例
- **可扩展**：新增设计内容只需添加新的文档

### 文档使用建议

1. **初次阅读**：从 `01-设计总览.md` 开始，了解项目整体情况
2. **深入理解**：根据需要阅读相关模块的设计文档
3. **扩展开发**：参考 `09-扩展设计.md` 了解扩展机制
4. **运维管理**：参考 `08-运维设计.md` 了解运维策略
5. **多机器人部署**：参考 `10-多机器人管理.md` 了解多机器人管理方案

### 文档更新

当以下情况发生时，需要更新相应的设计文档：

1. **新增功能**：更新相关模块的设计文档
2. **架构调整**：更新架构设计文档
3. **技术变更**：更新技术设计文档
4. **运维优化**：更新运维设计文档
5. **新增渠道**：更新渠道层设计文档

### 文档格式

- 使用 Markdown 格式
- 支持代码高亮
- 支持表格和列表
- 支持链接和引用
