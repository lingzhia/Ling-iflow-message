# Ling-iflow 设计总览

## 项目概述

Ling-iflow 是一个 iflow CLI 交互模式管理工具，通过 tmux 管理和监控 iflow CLI 会话，实现与企业微信的双向消息同步。专注于提供轻量级的交互模式管理功能。

### 核心目标

1. **通过 tmux 管理 iflow CLI 会话**
   - 在后台启动和管理 iflow CLI 进程
   - 支持多个独立的 iflow 实例（多 tmux 会话）
   - 提供 iflow CLI 的远程控制能力

2. **通过 tmux capture-pane 直接读取 tmux 输出来捕获 AI 回复**
   - 使用 `tmux capture-pane` 命令捕获 iflow CLI 的输出
   - 从 tmux 输出中提取带有 ✦ 标记的消息
   - 支持消息去重和过滤
   - 支持实时监控 iflow 的生成状态（生成中/已完成）

3. **支持企业微信消息与 iflow CLI 的双向同步**
   - 从企业微信接收用户消息，发送到 iflow CLI
   - 从 iflow CLI 捕获 AI 回复，发送到企业微信
   - 支持私聊和群聊场景

4. **提供简化的企业微信渠道，便于测试**
   - 支持应用机器人（回调模式）
   - 支持群机器人（Webhook 模式）
   - 提供测试工具，无需真实企业微信环境

5. **支持会话管理和连续对话**
   - 管理 iflow 的会话文件
   - 支持会话查询、创建、删除
   - 自动恢复上次会话，保持对话连续性

### 项目定位

Ling-iflow 专注于**交互模式管理**，不包含复杂的业务逻辑。它通过轻量级的方式连接企业微信和 iflow CLI，为用户提供便捷的 AI 助手交互体验。

**关键特点**：
- 轻量级：不修改 iflow CLI 源码，通过 tmux 进行外部控制
- 模块化：清晰的分层架构，各模块职责明确
- 异步架构：基于 asyncio 的高性能异步处理
- 易于扩展：支持渠道扩展、命令扩展、处理器扩展

### 层次说明

#### 1. 用户层
- **企业微信**：用户通过企业微信应用或群聊发送消息
- **CLI 命令**：用户通过命令行工具（ling-iflow）管理服务

#### 2. Channels 层
- **WechatWorkChannel**：企业微信渠道实现，支持应用机器人和群机器人
- **BaseChannel**：渠道抽象基类，定义统一接口

#### 3. Interactive 层（核心层）
- **SyncManager**：同步管理器，协调各个组件，实现双向同步（使用 SessionMonitor 监控 jsonl 文件）
- **BotIntegration**：机器人集成，连接企业微信和 iflow CLI（使用 tmux capture-pane 直接读取 tmux 输出）
- **SessionMonitor**：会话监控器，监控 session 文件变化（SyncManager 使用）
- **IFlowController**：iflow 控制器，通过 tmux 控制 iflow CLI
- **SessionManager**：会话管理器，管理 iflow 的会话文件
- **MessageDispatcher**：消息分发器，处理消息分发逻辑

#### 4. 系统层
- **tmux**：会话管理工具，运行 iflow CLI
- **iflow CLI**：AI 助手工具
- **session 文件**：iflow 的会话存储文件

#### 5. Config 层
- **Schema**：配置数据模型和验证规则
- **Loader**：配置加载器，加载和管理配置文件
- **配置文件**：用户配置文件（config.json）

## 核心设计原则

### 1. 模块化设计
- 清晰的分层架构，各层职责明确
- 高内聚、低耦合，便于维护和扩展
- 支持模块独立开发和测试

### 2. 异步架构
- 基于 asyncio 实现异步消息处理
- 使用 asyncio.Queue 实现消息队列
- 高并发处理能力，非阻塞 I/O

### 3. 灵活配置
- 支持多种配置方式（命令行参数、环境变量、配置文件）
- 配置加载优先级：命令行参数 > 环境变量 > 配置文件 > 默认值
- 支持配置验证和类型检查

### 4. 安全可靠
- 消息加密（AES-256-CBC）
- 权限控制（白名单机制）
- 输入验证和错误处理

### 5. 易于扩展
- 抽象基类设计，支持渠道扩展
- 命令注册机制，支持命令扩展
- 消息处理器链，支持处理器扩展

## 关键特性

### 1. 消息双向同步
- 企业微信 → iflow CLI：接收用户消息，发送到 iflow CLI
- iflow CLI → 企业微信：监控 AI 回复，发送到企业微信
- 支持私聊和群聊场景

### 2. 会话管理
- 自动管理 iflow 的会话文件
- 支持会话查询、创建、删除
- 自动恢复上次会话，保持对话连续性

### 3. 命令系统
- 支持多种命令：`/run`, `/new`, `/sessions`, `/status`, `/help` 等
- 支持直接发送消息（自动恢复会话）
- 智能提示和错误处理

### 4. 多机器人管理
- 支持配置多个企业微信机器人
- 每个机器人独立进程运行
- 支持多个 tmux 会话（多 iflow 实例）
- 灵活的资源管理（机器人、tmux 会话独立启停）

### 5. 测试工具
- 提供交互式测试工具（iflow_interactive.py）
- 提供企业微信调试工具（wechat_debug.py）
- 支持测试模式切换

## 技术栈

### 核心依赖
- **Python 3.10+**：编程语言
- **asyncio**：异步编程框架
- **pydantic**：数据验证和配置管理
- **pydantic-settings**：从环境变量和配置文件加载配置
- **loguru**：日志记录
- **typer**：CLI 命令行界面

### 企业微信依赖（可选）
- **httpx**：HTTP 客户端
- **aiohttp**：异步 HTTP 客户端
- **cryptography**：加密库（用于消息加解密）

### 开发依赖（可选）
- **pytest**：单元测试框架
- **pytest-asyncio**：异步测试支持

### 系统依赖
- **tmux**：会话管理工具
- **iflow CLI**：AI 助手工具
