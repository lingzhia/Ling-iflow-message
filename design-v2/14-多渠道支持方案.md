# 多渠道支持方案

## 概述

### 背景

当前项目配置紧耦合企业微信，存在以下问题：
1. 配置结构只支持企业微信，无法扩展其他渠道
2. 无法通过不同渠道启动项目（如模拟器、Telegram 等）
3. 添加新渠道需要修改配置结构和代码逻辑

### 目标

实现灵活的多渠道支持，允许：
- 通过不同渠道启动项目（企业微信、模拟器、Telegram 等）
- 支持渠道配置的灵活扩展
- 保持向后兼容性，默认行为不变

### 核心原则

**配置抽象化**：将渠道配置抽象为通用结构
**类型驱动**：通过 `type` 字段区分不同渠道
**向后兼容**：默认行为保持不变
**灵活扩展**：添加新渠道只需配置，无需修改代码

## 配置结构设计

### 新增配置段

**simulator_channels** - 模拟器渠道配置
```json
{
  "simulator_channels": [
    {
      "name": "simulator1",
      "enabled": false,
      "host": "localhost",
      "port": 19999,
      "tmux_session": "iflow1"
    }
  ]
}
```

**groups** - 渠道组配置
```json
{
  "groups": {
    "g1": ["wechat_bot1", "iflow_iflow1"],
    "g2": ["wechat_bot2", "iflow_iflow2"],
    "g_simulator": ["simulator1", "iflow_iflow1"]
  }
}
```

### 配置字段说明

**simulator_channels 配置**：
- `name`: 渠道唯一标识符（必需）
- `enabled`: 是否启用（必需）
- `host`: 监听地址（默认：localhost）
- `port`: 监听端口（默认：19999）
- `tmux_session`: 绑定的 iflow 会话（必需）

**groups 配置**：
- 组名作为键
- 值为模块 ID 列表
- 支持跨渠道组合

## 启动方式设计

### 方式 1：通过组启动（推荐）

```bash
./manage.py start -g g1              # 启动企业微信渠道（默认）
./manage.py start -g g_simulator      # 启动模拟器渠道
```

**优势**：
- 简单直观
- 适合固定组合
- 便于管理

### 方式 2：通过渠道启动

```bash
./manage.py start --channel wechat_bot1  # 指定企业微信渠道
./manage.py start --channel simulator1  # 指定模拟器渠道
```

**优势**：
- 灵活性高
- 支持自定义组合
- 便于测试

### 方式 3：默认启动（向后兼容）

```bash
./manage.py start                      # 默认启动第一个启用的企业微信渠道
```

**优势**：
- 向后兼容
- 简单快捷
- 不破坏现有行为

## 模块类型设计

### 现有类型

| 类型 | 说明 | 配置来源 |
|------|------|---------|
| iflow | iflow 模块 | `tmux_sessions` |
| wechat | 企业微信渠道 | `bots` |

### 新增类型

| 类型 | 说明 | 配置来源 |
|------|------|---------|
| simulator | 模拟器渠道 | `simulator_channels` |
| telegram | Telegram 渠道（未来） | `telegram_channels` |

### 创建逻辑

**bot.py 中的模块创建**：
```python
if module_type == "iflow":
    from ..modules.iflow import IFlowModule
    module = IFlowModule(module_id=module_id, **config)
elif module_type == "wechat":
    from ..modules.channel import WeChatChannel
    module = WeChatChannel(module_id=module_id, config=config)
elif module_type == "simulator":
    from ..modules.channel import SimulatorChannel
    module = SimulatorChannel(module_id=module_id, config=config)
elif module_type == "command":
    from ..modules.command import CommandHandler
    module = CommandHandler(message_bus=self.message_bus)
else:
    raise ValueError(f"未知的模块类型: {module_type}")
```

## 工作流程

### 默认启动流程

```
用户执行: ./manage.py start
  ↓
manage.py 检查参数：无 --channel，无 --group
  ↓
manage.py 选择默认行为：启动第一个启用的企业微信渠道
  ↓
bot.py 读取 config.json 中的 bots 配置
  ↓
查找第一个 enabled=true 的企业微信 bot
  ↓
创建 WeChatChannel 并启动
  ↓
服务运行中
```

### 指定渠道启动流程

```
用户执行: ./manage.py start --channel simulator1
  ↓
manage.py 检查参数：有 --channel 参数
  ↓
manage.py 优先级处理：--channel 参数优先
  ↓
bot.py 读取 config.json 中的 simulator_channels 配置
  ↓
查找 name="simulator1" 的配置
  ↓
创建 SimulatorChannel 并启动
  ↓
服务运行中
```

### 指定组启动流程

```
用户执行: ./manage.py start -g g_simulator
  ↓
manage.py 检查参数：有 --group 参数，无 --channel
  ↓
manage.py 处理组逻辑：--group 参数优先
  ↓
bot.py 读取 config.json 中的 groups 配置
  ↓
查找组 "g_simulator" 的模块列表
  ↓
逐个创建并启动模块
  ↓
服务运行中
```

## 优先级设计

### 参数优先级

1. **--channel**（最高优先级）
2. **--group**（中等优先级）
3. **默认行为**（最低优先级）

### 决策逻辑

```python
if channel is specified:
    # 启动指定渠道
    pass
elif group is specified:
    # 启动指定组
    pass
else:
    # 默认启动第一个启用的企业微信渠道
    pass
```

### 示例

| 命令 | 结果 |
|------|------|
| `./manage.py start --channel simulator1` | 只启动 simulator1 渠道 |
| `./manage.py start -g g1` | 启动 g1 组（wechat_bot1 + iflow_iflow1） |
| `./manage.py start` | 默认启动第一个启用的企业微信渠道 |

## 模块 ID 规范

### 企业微信渠道

- 命名格式：`wechat_<bot_name>`
- 示例：`wechat_bot1`, `wechat_bot2`

### 模拟器渠道

- 命名格式：`simulator_<name>`
- 示例：`simulator1`, `simulator_test`

### iflow 模块

- 命名格式：`iflow_<session_name>`
- 示例：`iflow_iflow1`, `iflow_iflow2`

## 向后兼容性

### 保持不变的部分

1. **配置格式**：`bots` 配置保持不变
2. **默认行为**：不指定渠道时，默认启动企业微信
3. **现有命令**：`./manage.py start -g g1` 仍然有效

### 新增的功能

1. **模拟器支持**：可以启动模拟器渠道
2. **渠道启动**：可以指定特定渠道启动
3. **灵活组合**：支持自定义渠道组合

## 错误处理

### 配置错误

**缺少必需字段**：
- 提示用户检查配置
- 提供配置示例

**无效的渠道类型**：
- 提示可用的渠道类型
- 列出当前支持的渠道

### 启动错误

**渠道不存在**：
- 提示检查配置
- 列出可用的渠道

**端口冲突**：
- 提示修改端口配置
- 或选择其他端口
