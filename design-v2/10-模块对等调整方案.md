| 功能 | 影响 | 优先级 |
|------|------|--------|
| **状态反馈** | 用户不知道 iflow 是否在生成中 | P0 |
| **消息分类显示** | 无法区分回复和思考 | P1 |
| **scope 支持** | 无法查看完整输出 | P1 |
| **拒绝机制反馈** | 生成中发送消息无提示 | P1 |
| **错误处理增强** | 错误反馈不明确 | P2 |
| **中断支持** | 无法中断请求 | P2 |

#### 当前消息处理流程

```
企业微信消息
    ↓
WeChatModule._on_wechat_message()
    ↓
CommandHandler.parse_command()
    ↓
┌─────────────────────────────────────┐
│ 命令 → 直接执行                      │
│ 普通消息 → 发送到消息总线            │
└─────────────────────────────────────┘
    ↓
MessageBus.route()
    ↓
IFlowModule.receive()
    ↓
IFlowModule.send()
    ↓
返回 Response
    ↓
（WeChatModule 未处理 Response）
```

```
IFlowModule 输出
    ↓
IFlowModule.send_to_bus()
    ↓
MessageBus.route()
    ↓
WeChatModule._on_receive()
    ↓
直接发送到企业微信（无处理）
```

#### 问题分析

1. **无状态反馈**：
   - 用户发送消息后，不知道 iflow 是否正在生成
   - Response 被忽略，拒绝信息未传达给用户

2. **无消息分类**：
   - ✦ 和 ✻ 消息都显示，无法区分
   - 用户可能看到"思考中"消息，体验不佳

3. **无 scope 支持**：
   - 无法切换查看完整输出
   - 默认只显示回复，无法查看思考过程

4. **错误处理不足**：
   - 发送失败、生成中拒绝等情况未明确告知用户

```python
class WeChatModule(BaseModule):
    def __init__(self, module_id: str, config: Dict[str, Any]):
        super().__init__(module_id)
        
        self.config = config
        self.channel = WeChatChannel(config)
        self.command_handler = CommandHandler()
        
        # 新增：状态管理
        self._pending_messages: Dict[str, Dict] = {}  # 待处理消息
        self._message_callbacks: Dict[str, Callable] = {}  # 消息回调
        
        # 设置消息处理器
        self.channel.set_message_handler(self._on_wechat_message)
    
    async def _on_wechat_message(self, wechat_msg: Dict[str, Any]) -> None:
        """企业微信消息回调"""
        try:
            content = wechat_msg.get("content", "")
            chat_id = wechat_msg.get("chat_id", "")
            sender_id = wechat_msg.get("sender_id", "")
            is_group = wechat_msg.get("is_group", False)
            
            # 解析命令
            parsed = self.command_handler.parse_command(content)
            
            # 如果是命令，执行命令并回复
            if parsed.get("is_command"):
                result = await self.command_handler.execute(parsed, chat_id)
                if result:
                    await self.channel.send_message(result, chat_id, is_group)
                return
            
            # 普通消息：发送到消息总线并等待 Response
            message = Message(
                id=Message.generate_id(),
                type=MessageType.TEXT,
                content=MessageContent(type=MessageType.TEXT, text=content),
                from_module=self.module_id,
                chat_id=chat_id,
                user_id=sender_id,
                is_group=is_group,
                metadata={
                    "msg_type": wechat_msg.get("msg_type", "text"),
                    "require_response": True  # 标记需要返回 Response
                }
            )
            
            # 发送到消息总线
            if self.message_bus:
                # 发送消息并获取 Response
                response = await self.send_to_bus_with_response(message)
                
                # 处理 Response
                if response:
                    await self._handle_response(response, chat_id, is_group)
                else:
                    logger.warning(f"[{self.module_id}] 未收到 Response")
                    
        except Exception as e:
            logger.error(f"[{self.module_id}] 处理企业微信消息失败: {e}", exc_info=True)
    
    async def send_to_bus_with_response(self, message: Message) -> Optional[Dict]:
        """发送消息到总线并等待 Response
        
        Args:
            message: 消息对象
            
        Returns:
            Response 字典，如果超时则返回 None
        """
        if not self.message_bus:
            return None
        
        # 创建响应等待器
        response_future = asyncio.Future()
        
        # 注册回调
        message_id = message.id
        
        def on_response(msg: Message):
            if msg.metadata.get("response_to") == message_id:
                response_future.set_result(msg.metadata.get("response"))
        
        # 临时订阅
        self.message_bus.subscribe_temporary(message_id, on_response)
        
        # 发送消息
        await self.send_to_bus(message)
        
        # 等待响应（超时 60 秒）
        try:
            response = await asyncio.wait_for(response_future, timeout=60.0)
            return response
        except asyncio.TimeoutError:
            logger.warning(f"[{self.module_id}] 等待 Response 超时: {message_id}")
            return None
    
    async def _handle_response(self, response: Dict, chat_id: str, is_group: bool) -> None:
        """处理 Response
        
        Args:
            response: Response 字典
            chat_id: 聊天 ID
            is_group: 是否群聊
        """
        success = response.get("success", False)
        error = response.get("error", "")
        message = response.get("message", "")
        duration = response.get("duration", 0)
        
        if not success:
            # 发送失败或被拒绝
            if error == "iflow_generating":
                # 生成中拒绝
                notification = f"""⏳ iflow 正在处理中...

已持续 {duration} 秒，请稍后再试。"""
                await self.channel.send_message(notification, chat_id, is_group)
            else:
                # 其他错误
                notification = f"❌ {message}"
                await self.channel.send_message(notification, chat_id, is_group)
        else:
            # 发送成功
            logger.info(f"[{self.module_id}] 消息已发送: {message}")
```

async def _on_receive(self, message: Message) -> None:
    """接收消息时的钩子方法"""
    try:
        # 提取消息内容
        content = message.content.text if message.content else ""
        
        if not content:
            logger.warning(f"[{self.module_id}] 收到空消息")
            return
        
        # 获取消息类型
        msg_type = message.metadata.get("type", "reply")
        marker_type = message.metadata.get("marker_type", "")
        
        # 获取聊天ID
        chat_id = message.metadata.get("chat_id") or message.chat_id or self.config.get("user_id", "")
        is_group = message.is_group
        
        # 根据消息类型处理
        if msg_type == "reply":
            # 回复消息，正常显示
            success = await self.channel.send_message(content, chat_id, is_group)
        elif msg_type == "other":
            # 其他消息（思考中），可以标记或隐藏
            # 方案1：标记显示
            formatted_content = f"💭 {content}"
            success = await self.channel.send_message(formatted_content, chat_id, is_group)
            
            # 方案2：隐藏（如果用户不需要）
            # success = True  # 不发送
        elif msg_type == "complete":
            # 完成通知
            logger.info(f"[{self.module_id}] 消息生成完成")
            # 可以选择是否发送完成通知
            # success = await self.channel.send_message("✅ 回复完成", chat_id, is_group)
        
        if success:
            logger.info(f"[{self.module_id}] 消息已发送到企业微信")
        else:
            logger.error(f"[{self.module_id}] 消息发送失败")
            
    except Exception as e:
        logger.error(f"[{self.module_id}] 处理消息失败: {e}", exc_info=True)

## 实施优先级

### P0（高优先级）

| 任务 | 模块 | 工作量 | 影响 |
|------|------|--------|------|

## 总结

### 关键发现

1. **IFlow 模块已经很完善**：状态管理、消息分类、scope 过滤等核心功能都已实现
2. **WeChatModule 需要增强**：缺少状态反馈、消息分类、scope 支持
3. **CommandHandler 需要扩展**：需要添加 scope 切换、状态查询命令
4. **MessageBus 需要优化**：需要支持 Response 返回和临时订阅

### 建议实施路线

1. **先实现 P0 功能**：状态反馈和拒绝机制反馈，这是用户体验的关键
2. **再实现 P1 功能**：消息分类、scope 切换、状态查询
3. **最后实现 P2 功能**：高级功能，根据需求决定

### 预期效果

- ✅ 用户能实时了解 iflow 状态
- ✅ 消息显示更清晰（回复/思考分离）
- ✅ 支持 scope 切换，灵活控制显示内容
- ✅ 拒绝机制有明确反馈
- ✅ 状态查询更方便
