# 企业微信渠道设计

## 一、概述

WeChatChannel（企业微信渠道）是 Ling-iflow 项目与 企业微信 平台交互的桥梁，负责接收和发送企业微信消息。

---

## 二、职责

### 2.1 核心职责

- 接收企业微信回调
- 解析消息内容
- 发送消息到企业微信
- 处理企业微信特定的消息格式

### 2.2 WeChatChannel 职责功能

| 功能 | 说明 | 原因 | 状态 |
|------|------|------|------|
| 消息确认机制 | 收到企业微信消息后立即发送确认 | 属于企业微信层面的用户体验 | ✅ 已实现 |
| 消息去重机制 | 使用 MsgId 避免重复处理 | 属于企业微信消息处理的基础功能 | ✅ 已实现 |
| 详细日志 | 收发消息的详细记录 | 属于企业微信模块的调试功能 | ✅ 已实现 |
| 启动通知 | 模块启动时发送通知 | 属于企业微信渠道的体验功能 | ✅ 已实现 |
| 停止通知 | 模块停止时发送通知 | 属于企业微信渠道的体验功能 | ✅ 已实现 |

**WeChatChannel 职责**：纯粹的企业微信消息收发，不处理业务逻辑

---

## 三、主要功能

### 3.1 消息确认机制

- 收到企业微信消息后，立即发送确认消息
- 确认消息内容：包含"收到消息"和"正在处理"提示
- 避免用户因未看到响应而重复发送

### 3.2 消息去重机制

- 使用 MsgId 进行去重
- 维护消息 ID 缓存（TTL: 1小时）
- 定期清理过期缓存

### 3.3 详细日志

- 收到消息时打印详细信息
- 发送消息时打印详细信息
- 便于调试和问题排查

## 四、配置字段

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 渠道唯一标识符 |
| `enabled` | boolean | 是 | 是否启用 |
| `corp_id` | string | 是 | 企业 ID |
| `agent_id` | string | 是 | 应用 AgentId |
| `secret` | string | 是 | 应用 Secret |
| `user_id` | string | 是 | 用户账号（用于发送消息） |
| `token` | string | 是 | 回调配置的 Token |
| `encoding_aes_key` | string | 是 | 回调配置的 EncodingAESKey |
| `callback_host` | string | 否 | 回调服务监听地址（默认：0.0.0.0） |
| `callback_port` | integer | 否 | 回调服务端口（默认：8788） |
| `stream_mode` | boolean | 否 | 是否启用 Stream Mode（默认：false） |
| `poll_interval` | integer | 否 | 轮询间隔，秒（默认：5） |
| `allow_from` | array | 否 | 允许的用户 ID 白名单 |
| `group_policy` | string | 否 | 群聊消息响应策略（默认：mention） |
| `group_allow_from` | array | 否 | 群聊白名单 |

## 五、消息格式

### 5.1 接收消息格式

企业微信回调消息经过 MessageConverter 转换为标准 Message 格式：

| 字段 | 类型 | 说明 |
|------|------|------|
| content | str | 消息内容 |
| chat_id | str | 会话 ID |
| source | str | 消息来源模块 ID |
| metadata | dict | 元数据（包含MsgId等） |

### 5.2 发送消息格式

标准 Message 经过 MessageConverter 转换为企业微信消息格式。

## 九、常见问题

### Q1: 消息发送失败

**可能原因：**
- 应用未启用
- 权限配置不完整
- 用户不在启用范围内

**解决方案：**
1. 检查应用是否已启用
2. 检查权限配置是否完整
3. 确认用户在启用范围内

### Q2: 收不到消息回调

**可能原因：**
- 回调配置错误
- Token 配置错误
- EncodingAESKey 配置错误

**解决方案：**
1. 检查回调配置
2. 重新验证 Token
3. 确认 EncodingAESKey 配置

### Q3: 如何开启消息确认机制？

消息确认机制是 WeChatChannel 的内置功能，默认启用。无需额外配置。

### Q4: 如何配置白名单？

在配置中添加 `allow_from` 字段：
```json
{
  "allow_from": ["user_id_1", "user_id_2"]
}
```

### 10.2 架构位置

WeChatChannel 在架构中的位置：

```
企业微信消息
    ↓
WeChatChannel（接收/发送）
    ↓
MessageConverter（格式转换）
    ↓
MessageBus（消息路由）
    ↓
IFlowModule（业务处理）
```
