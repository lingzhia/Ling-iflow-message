# 命令系统设计方案

## 一、方案概述

### 1.1 背景和目标

当前项目通过企业微信、模拟器等渠道与用户交互，用户可以通过特定的命令（以 `/` 开头）来控制系统、查询状态、管理会话等。命令系统是用户与系统交互的重要接口，需要提供清晰、易用、可扩展的命令功能。

**核心目标：**
- 提供统一的命令解析和执行机制
- 支持多种类型的命令（会话管理、状态查询、渠道管理等）
- 易于扩展新的命令
- 支持命令透传（未知命令传递给 iflow 处理）
- 提供友好的帮助和错误提示

### 1.2 设计原则

**单一职责原则**
- CommandHandler 只负责命令解析和执行
- 不依赖具体的业务逻辑模块
- 通过消息总线与其他模块通信

**职责清晰**
- 命令处理独立于具体业务模块
- 每个命令有明确的职责和功能
- 命令结果格式统一

**易于扩展**
- 支持动态注册自定义命令
- 提供清晰的命令注册接口
- 支持命令别名和参数

**透传机制**
- 未知命令自动透传给 iflow 处理
- 保留 iflow 原生命令的完整性
- 避免命令冲突

### 2.2 CommandHandler 核心组件

**CommandHandler 类**
- 位置：`src/modules/command/handler.py`
- 职责：命令解析、命令执行、命令注册
- 依赖：MessageBus、ModuleManager、Bot 实例

**主要方法：**
- `__init__(message_bus, manager)`: 初始化命令处理器
- `parse_command(content)`: 解析用户消息，提取命令和参数
- `execute(parsed, chat_id)`: 执行命令
- `_register_builtin_commands()`: 注册内置命令
- `set_message_bus(bus)`: 设置消息总线
- `set_manager(manager)`: 设置模块管理器
- `set_bot(bot)`: 设置 bot 实例

### 3.1 会话管理命令

#### 3.1.1 `/new` - 开始新会话

**功能：**
- 清除 iflow 的当前上下文
- 创建新的空白会话
- 重新开始对话

**使用方法：**
```
/new
```

**实现逻辑：**
```python
async def _cmd_new(self, args: str, chat_id: str) -> str:
    """新建会话命令"""
    if not self.bus:
        return "❌ 消息总线未初始化"
    
    # 查找 iflow 模块并创建新会话
    for module_id, module in self.bus.modules.items():
        if module_id.startswith("iflow_") and hasattr(module, 'create_new_session'):
            result = module.create_new_session()
            if result.get("success"):
                return "✅ 已开始新会话，下次命令将从空白上下文开始"
            else:
                return f"❌ 创建新会话失败: {result.get('message', '未知错误')}"
    
    return "❌ 没有可用的 iflow 模块"
```

**返回结果：**
- 成功：`✅ 已开始新会话，下次命令将从空白上下文开始`
- 失败：`❌ 创建新会话失败: <错误信息>`
- 无模块：`❌ 没有可用的 iflow 模块`

```python
async def _cmd_history(self, args: str, chat_id: str) -> str:
    """查看状态历史命令"""
    if not self.manager:
        return "❌ 模块管理器未初始化"
    
    module_id = args.strip() if args.strip() else None
    
    if module_id:
        # 查看指定模块的历史
        if module_id not in self.manager.modules:
            return f"❌ 模块不存在: {module_id}"
        
        history = self.manager.get_state_history(module_id, limit=10)
        
        if not history:
            return f"ℹ️ 模块 {module_id} 没有状态历史记录"
        
        lines = [f"**{module_id} 状态历史** 📜\n"]
        for i, transition in enumerate(history, 1):
            timestamp = transition.timestamp.strftime("%H:%M:%S")
            lines.append(f"{i}. {timestamp} | {transition.from_state} → {transition.to_state}")
            if transition.reason:
                lines.append(f"   原因: {transition.reason}")
            if transition.details:
                details_str = ", ".join([f"{k}={v}" for k, v in transition.details.items()])
                lines.append(f"   详情: {details_str}")
        
        return "\n".join(lines)
    else:
        # 查看所有模块的历史
        lines = ["**所有模块状态历史** 📜\n"]
        
        for module_id in self.manager.modules.keys():
            history = self.manager.get_state_history(module_id, limit=5)
            
            if history:
                lines.append(f"**{module_id}**")
                for transition in history:
                    timestamp = transition.timestamp.strftime("%H:%M:%S")
                    lines.append(f"  {timestamp}: {transition.from_state} → {transition.to_state}")
                lines.append("")
        
        return "\n".join(lines)
```

```python
async def _cmd_tmux(self, args: str, chat_id: str) -> str:
    """tmux 管理命令"""
    parts = args.strip().split()
    
    if not parts:
        action = "list"
    else:
        action = parts[0].lower()
        args_str = ' '.join(parts[1:]) if len(parts) > 1 else ""
    
    if action == "list":
        # 列出所有 tmux 会话
        import subprocess
        
        try:
            result = subprocess.run(
                ["tmux", "list-sessions"],
                capture_output=True,
                text=True
            )
            
            if result.returncode == 0:
                sessions = result.stdout.strip()
                if not sessions:
                    return "✅ 当前没有运行的 tmux 会话"
                
                lines = ["**tmux 会话列表** 📋\n"]
                lines.append(sessions)
                return "\n".join(lines)
            else:
                return f"❌ 获取 tmux 会话列表失败: {result.stderr}"
        except Exception as e:
            return f"❌ 执行 tmux 命令失败: {e}"
```

```python
async def _cmd_channel(self, args: str, chat_id: str) -> str:
    """渠道管理命令"""
    if not self.bot:
        return "❌ Bot 实例未初始化"
    
    parts = args.strip().split()
    action = parts[0].lower()
    
    if action == "list":
        # 列出所有渠道
        channels = self.bot.list_channels()
        if not channels:
            return "❌ 没有可用的渠道"
        
        lines = ["**可用渠道列表** 📋\n"]

                channel_type = "企业微信" if "corp_id" in channel_info else "模拟器"
                enabled = channel_info.get("enabled", False)
                enabled_icon = "✅" if enabled else "❌"
                lines.append(f"- {enabled_icon} {channel} ({channel_type})")
        
        return "\n".join(lines)
```

## 四、命令解析和执行流程

### 4.1 命令解析

**parse_command() 方法**
```python
def parse_command(self, content: str) -> Dict[str, Any]:
    """解析用户消息，提取命令
    
    Args:
        content: 用户发送的消息
        
    Returns:
        解析结果字典，格式：
        {
            "is_command": bool,
            "cmd_type": str,  # "command" or "message"
            "cmd_name": Optional[str],
            "cmd_args": Optional[str],
            "raw_content": str
        }
    """
    content = content.strip()
    
    # 检查是否为命令（以 / 开头）
    if content.startswith("/"):
        parts = content.split(maxsplit=1)
        cmd_name = parts[0].lower()
        cmd_args = parts[1] if len(parts) > 1 else ""
        
        return {
            "is_command": True,
            "cmd_type": "command",
            "cmd_name": cmd_name,
            "cmd_args": cmd_args,
            "raw_content": content
        }
    
    # 普通消息
    return {
        "is_command": False,
        "cmd_type": "message",
        "cmd_name": None,
        "cmd_args": content,
        "raw_content": content
    }
```

**解析规则：**
1. 以 `/` 开头的消息为命令
2. 命令名不区分大小写（自动转换为小写）
3. 命令和参数用空格分隔
4. 参数可以为空

**示例：**
- `/new` → 命令名：`/new`，参数：空
- `/status` → 命令名：`/status`，参数：空
- `/history iflow_bot1` → 命令名：`/history`，参数：`iflow_bot1`
- `/channel start bot1` → 命令名：`/channel`，参数：`start bot1`
- `你好` → 非命令，普通消息

### 4.2 命令执行

**execute() 方法**
```python
async def execute(self, parsed: Dict[str, Any], chat_id: str = "") -> Optional[str]:
    """执行命令
    
    Args:
        parsed: 解析后的命令
        chat_id: 聊天 ID
        
    Returns:
        命令执行结果（回复消息），如果不是命令则返回 None
    """
    if not parsed.get("is_command"):
        return None
    
    cmd_name = parsed.get("cmd_name", "")
    cmd_args = parsed.get("cmd_args", "")
    
    # 检查命令是否存在
    if cmd_name in self._commands:
        try:
            result = await self._commands[cmd_name](cmd_args, chat_id)
            return result
        except Exception as e:
            logger.error(f"执行命令 {cmd_name} 失败: {e}", exc_info=True)
            return f"❌ 执行命令失败: {e}"
    
    # 未知命令：透传给 iflow 处理
    logger.info(f"未知命令，透传给 iflow: {cmd_name} {cmd_args}")
    return None
```

**执行流程：**
1. 检查是否为命令（`is_command`）
2. 检查命令是否已注册（`cmd_name in self._commands`）
3. 执行命令处理函数
4. 捕获异常并返回错误信息
5. 未知命令返回 `None`（透传给 iflow）

### 5.1 透传场景

**未知的斜杠命令：**
- 用户发送以 `/` 开头但未注册的命令
- 例如：`/run`、`/config`、`/exit`、`/clear` 等


**已知命令处理优化：**

### 5.2 透传流程

```
用户发送命令
    │
    ▼
渠道模块接收
    │
    ▼
解析命令
    │
    ├─→ 已知命令
    │       │
    │       ▼
    │   执行命令处理函数
    │       │
    │       ▼
    │   返回结果
    │       │
    │       ▼
    │   发送回复给用户
    │       │
    │       ▼
    │   结束（不发送到消息总线）
    │
    └─→ 未知命令
            │
            ▼
        创建消息对象
            │
            ▼
        发送到消息总线
            │
            ▼
        路由到 iflow 模块
            │
            ▼
        iflow 处理命令
            │
            ▼
        返回结果
```

### 5.3 透传优势

**保留 iflow 原生命令：**
- 用户可以直接使用 iflow 的所有命令
- 不需要在命令系统中重复实现 iflow 命令
- 保持 iflow 功能的完整性

**避免命令冲突：**
- 不需要担心命令名冲突
- 命令系统只处理特定于系统的命令
- iflow 命令由 iflow 自行处理

**避免重复发送：**
- 已知命令执行后直接返回，不再发送到消息总线
- 避免已知命令被重复发送到 iflow
- 提高系统效率

**易于维护：**
- 命令系统和 iflow 命令解耦
- iflow 命令更新不需要修改命令系统
- 减少重复代码

```python
class MessageBus:
    """消息总线"""
    
    def __init__(self, module_manager=None):
        self.module_manager = module_manager
        self.modules = {}
        self.bindings = {}
    
    async def route(self, message: Message) -> bool:
        """路由消息"""
        from_module = message.from_module
        
        # 检查是否为命令
        if message.content.text.startswith("/"):
            # 命令消息：先尝试命令处理器
            command_module_id = f"{from_module}_command"
            
            if command_module_id in self.modules:
                command_module = self.modules[command_module_id]
                result = await command_module.execute_command(message)
                
                if result is not None:
                    # 命令已处理，发送结果回发送方
                    result_message = Message(
                        id=Message.generate_id(),
                        type=MessageType.TEXT,
                        content=MessageContent(type=MessageType.TEXT, text=result),
                        from_module=command_module_id,
                        to_module=from_module
                    )
                    await self.send_to_module(result_message)
                    return True
        
        # 普通消息或未处理命令：正常路由
        return await self.send_to_module(message)
```
