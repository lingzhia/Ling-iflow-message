## 二、企业微信测试工具

### 2.1 工具位置

`tools/wechat_test_tool.py`

### 2.2 功能

| 命令 | 说明 |
|------|------|
| `listen` | 监听模式，接收企业微信回调消息 |
| `send "消息"` | 发送消息到企业微信 |
| `test` | 测试配置，验证企业微信配置是否正确 |

### 2.3 使用示例

```bash
# 启动监听模式
python3 tools/wechat_test_tool.py listen

# 发送测试消息
python3 tools/wechat_test_tool.py send "Hello, iflow!"

# 测试配置
python3 tools/wechat_test_tool.py test
```

### 2.4 实现原理

企业微信测试工具通过直接调用企业微信 API 来：
1. 发送消息到指定用户
2. 接收消息回调（需要配置回调 URL）
3. 验证配置的正确性

## 三、模拟器测试客户端

### 3.1 工具位置

`tools/test_client.py`

### 3.2 功能

**交互模式：**
- 提供交互式命令行界面
- 发送消息到 SimulatorChannel
- 接收并显示 iflow 的回复

**支持的命令：**
| 命令 | 说明 |
|------|------|
| `/help` | 显示帮助信息 |
| `/quit` 或 `/exit` | 退出工具 |
| `/status` | 显示连接状态 |
| `/stats` | 显示消息统计 |

### 3.3 使用示例

```bash
# 启动交互模式
python3 tools/test_client.py

# 命令行模式发送消息
python3 tools/test_client.py --send "1+1=?"

# 指定端口
python3 tools/test_client.py --send "消息" localhost 20000
```

### 3.4 通信协议

使用 JSON + 长度前缀的 Socket 通信协议：

```
[4字节长度][JSON消息]
```

详细协议说明请参考 [07-模拟器渠道设计.md](./07-模拟器渠道设计.md)。

## 四、Tmux 查看工具

### 4.1 工具位置

`tools/tmux_viewer.py`

### 4.2 功能

- 查看当前运行的 tmux 会话列表
- 查看指定 tmux 会话的当前内容
- 捕获 tmux 界面快照

### 4.3 使用示例

```bash
# 查看所有 tmux 会话
python3 tools/tmux_viewer.py

# 查看指定会话
python3 tools/tmux_viewer.py --session bot1+iflow

# 实时跟踪会话输出
python3 tools/tmux_viewer.py --session bot1+iflow --follow
```

## 六、架构设计

### 6.1 工具与项目关系

```
┌─────────────────────────────────────────────────────────┐
│                      工具层                             │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐      │
│  │ wechat_test │  │ test_client │  │ tmux_viewer │      │
│  │ _tool.py    │  │ .py         │  │ .py         │      │
│  └─────────────┘  └─────────────┘  └─────────────┘      │

                          │
                          │ 通信
                          ▼

│  │ WeChat      │  │ Simulator   │  │ IFlow       │      │
│  │ Channel     │  │ Channel     │  │ Module      │      │
│  └─────────────┘  └─────────────┘  └─────────────┘      │
└─────────────────────────────────────────────────────────┘
```

### 6.2 设计原则

| 原则 | 说明 |
|------|------|
| 独立性 | 工具完全独立于项目运行，不依赖项目代码 |
| 易用性 | 提供简洁的命令行界面 |
| 可扩展 | 易于添加新的测试场景 |
| 调试友好 | 提供详细的日志输出 |
