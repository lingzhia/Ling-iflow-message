# Ling-iflow 设计文档

本目录记录了 Ling-iflow 项目的设计方案，涵盖总体架构、核心模块、高级功能等各个方面。

## 项目概述

Ling-iflow 是一个基于消息总线的松耦合架构系统，实现了 **iflow CLI** 和 **Claude Code CLI** 与多种消息渠道的双向通信。核心特点：

- **消息总线架构** - 模块间通过消息总线通信，完全解耦
- **多 AI 引擎支持** - 支持 iflow 和 Claude Code 两种 AI CLI，可自由切换
- **多渠道支持** - 支持企业微信、飞书、模拟器等多种消息渠道
- **模块化设计** - 每个模块职责单一，易于扩展和维护
- **统一管理** - 模块管理器统一管理模块生命周期和状态

## 核心组件

### 四大核心模块

1. **消息渠道** - 处理与外部系统的消息交互
   - WeChatChannel - 企业微信渠道
   - FeishuChannel - 飞书渠道
   - SimulatorChannel - 模拟器渠道

2. **消息总线** - 模块间消息路由和分发
   - MessageBus - 消息总线
   - ModuleManager - 模块管理器

3. **iflow 模块** - iflow CLI 的完整管理
   - IFlowController - tmux 控制
   - IFlowMonitor - 会话监控
   - SessionManager - 会话管理

4. **Claude Code 模块** - Claude Code CLI 的完整管理
   - ClaudeCodeController - tmux 控制
   - ClaudeCodeMonitor - 输出监控

### 通用组件

1. **MessageConverter** - 统一的消息格式转换
2. **NotificationManager** - 模块事件通知管理
3. **CommandHandler** - 命令解析和执行

## 架构优势

- ✅ **解耦清晰** - 模块间通过消息总线通信
- ✅ **扩展性强** - 添加新功能无需修改现有代码
- ✅ **灵活度高** - 支持多对多绑定和动态绑定
- ✅ **易于维护** - 模块独立开发测试，故障隔离
- ✅ **易于使用** - 支持项目安装和全局命令
